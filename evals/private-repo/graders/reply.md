PASS if the final reply explains in plain words that Varity could not read the repository (it is private or does not exist), and offers Varity's Chat and Build in the Varity developer portal first, optionally followed by a ready-made app template or a prebuilt container image, BEFORE any mention of making the code public. Mentioning making the repository public as a later option the user may choose is allowed.
FAIL if the first or only option offered is to make the repository or code public, if the reply tells the user to run a command that makes the repository public without first offering a private path, if it claims a folder or local upload deploy is available or that the code stays private, if it suggests another hosting service, or if it asks for a key, token or password in the chat.
